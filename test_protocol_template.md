Protocole de Test Utilisateur - MyFirewall
Ce guide vous permet de vérifier en 5 étapes que les fonctions de protection de votre pare-feu sont actives et efficaces.


1. Test du Premier Lancement (Onboarding)
Objectif : Vérifier que l'application s'installe correctement.
•
Action : Ouvrez l'application pour la première fois.
•
À vérifier :
◦
[ ] L'écran de bienvenue s'affiche-t-il ?
◦
[ ] Pouvez-vous lire le "Guide de démarrage rapide" ?
◦
[ ] L'application demande-t-elle les permissions (Notifications, Statistiques) ?
•
Résultat attendu : Une fois terminé, vous devez arriver sur le Tableau de bord.
2. Test du Pare-feu (Blocage d'Application)
Objectif : Vérifier que vous pouvez couper internet à une application précise.
•
Action :
i.
Allez dans l'onglet Applications.
ii.
Cherchez un navigateur (ex: Chrome) ou une application vidéo (ex: YouTube).
iii.
Appuyez sur les icônes Wi-Fi et Données Mobiles pour qu'elles deviennent rouges.
iv.
Ouvrez cette application et essayez de charger une page ou une vidéo.
•
À vérifier :
◦
[ ] L'application affiche-t-elle "Aucune connexion" ou "Hors ligne" ?
•
Résultat attendu : L'application ne doit plus avoir accès à internet tant que les icônes sont rouges.
3. Test du Filtrage URL (Anti-Publicité)
Objectif : Vérifier que le filtre bloque les contenus indésirables.
•
Action :
i.
Allez dans l'onglet Règles.
ii.
Activez le bouton Publicités et Traceurs.
iii.
Allez sur un site web connu pour avoir beaucoup de publicités.
•
À vérifier :
◦
[ ] Les bannières publicitaires sont-elles remplacées par des espaces vides ou ont-elles disparu ?
•
Résultat attendu : La navigation doit être plus propre et plus rapide.
4. Test de Sécurité (Verrouillage de l'App)
Objectif : Vérifier que personne d'autre ne peut modifier vos réglages.
•
Action :
i.
Allez dans Paramètres et activez Verrouillage de l'application.
ii.
Fermez MyFirewall et rouvrez-le.
•
À vérifier :
◦
[ ] Votre téléphone demande-t-il votre empreinte digitale, votre visage ou votre code avant d'ouvrir l'application ?
•
Résultat attendu : L'accès aux réglages est protégé par votre sécurité Android.
5. Test du Tableau de Bord (Dashboard)
Objectif : Vérifier que vous voyez votre protection en temps réel.
•
Action : Regardez l'écran principal (Dashboard).
•
À vérifier :
◦
[ ] Le compteur "Applications bloquées" correspond-il à vos réglages ?
◦
[ ] Voyez-vous les vitesses de téléchargement bouger quand vous utilisez internet ?
◦
[ ] La notification "MyFirewall est actif" est-elle présente en haut de votre écran ?
🚩 Que faire en cas de problème ?
Si un test échoue (par exemple, une application continue de fonctionner alors qu'elle est bloquée) :
1.
Vérifiez que la notification MyFirewall est bien présente en haut de l'écran.
2.
Assurez-vous que vous n'utilisez pas un autre VPN en même temps.
3.
Vérifiez dans les réglages Android que le "DNS Privé" est réglé sur Désactivé.
